\# ChessMate ♞



ChessMate is a full-stack Chess Tournament Management System built with React, Node.js, Express and MongoDB.



\## Features



\- Create chess tournaments

\- Register players

\- Generate round pairings

\- Enter match results

\- Automatic points calculation

\- Tournament standings

\- Admin login

\- Tournament filtering



\## Tech Stack



\- React + Vite

\- Node.js

\- Express.js

\- MongoDB Atlas

\- Mongoose

\- Git \& GitHub
